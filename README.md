This is a group of example basic financial 
coding projects I worked on to help learn 
how to code and apply that learning to real 
scenarios. The projects are described below:

Coinflip simulator with a mean calculated 
over the whole data set at a point X.

A Dice roll Simulator displaying the probability
distribution of rolling N number of X sided dice.

A Moving mean and Sharpe Ratio program, which pulls 
5 years of historical stock data and market data,
and then calculates a 15 day short moving mean, a 50 
day long moving mean, the stock's beta, the stock's CAPM
expected return, and the stock's Sharpe Ratio
